# Overall GATE CSE Priority Ranking

## Tier 1 (Must Master)

* OS: Memory Management
* DBMS: SQL + Normalization + FDs
* CN: IP + TCP + Subnetting
* TOC: DFA/NFA + CFG
* DSA: DP + Trees + Graphs + Sorting

## Tier 2 (Very Important)

* OS: Processes, Scheduling
* DBMS: Transactions, Serializability
* CN: Routing, CRC
* TOC: PDA, Turing Machine
* DSA: Greedy, Heap

## Tier 3 (Revision Topics)

* OS: File Systems
* DBMS: File Organization
* CN: MAC Protocols
* TOC: Computability
* DSA: Backtracking

# 80/20 Rule for GATE

Study these first:

1. OS → Paging + Virtual Memory
2. DBMS → SQL + FDs + BCNF
3. CN → IP + TCP + Subnetting
4. TOC → DFA/NFA + CFG
5. DSA → DP + Trees + Graphs + Sorting

These topics alone typically cover 60–70% of technical questions in GATE CSE.
